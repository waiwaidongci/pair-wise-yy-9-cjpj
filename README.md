# 蓝晒洗水回用与残留放行模块

运行：

```bash
npm start
```

访问 `http://localhost:3040`。数据保存在 `data/water-reuse.json`。

## 业务拆分

| 文件 | 职责 |
| --- | --- |
| `wash-entry.js` | 入口层：HTTP 路由、请求解析、页面（开洗 / 换水 / 取样 / 更正 / 筛选） |
| `wash-rules.js` | 判定层：开洗四闸、底片锁定、换水取样、残留放行、更正失效重算、幂等重放 |
| `wash-store.js` | 存储层：JSON 文件持久化、洗槽占用视图、事件流、种子数据 |

## 规则

- 同张底片洗片结束前不能开第二洗程；重复提交（相同 requestId）重放首条结果。
- 开洗填写水批、电导率、银离子、滤芯号、操作者。水批过期、银离子 > 0.5 mg/L、
  电导率 > 800 μS/cm 或滤芯被占用时只转待换水，不占洗槽、不占滤芯。
- 换水必须由开洗人之外的另一人登记；换水后隔半小时连续取样两次，
  银离子均 ≤ 0.1 mg/L 且压差 ≤ 10 kPa 才可放行，放行时才分配洗槽。
- 更正水批、滤芯或水源会产生只读旧版本，原放行失效并回到待换水重算。
